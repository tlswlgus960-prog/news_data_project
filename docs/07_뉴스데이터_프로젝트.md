# 07. 뉴스 데이터 프로젝트

## 학습목표
- Oracle에 저장된 뉴스를 Python으로 분석할 수 있다.
- Pandas와 Plotly를 활용하여 데이터를 시각화할 수 있다.
- FastAPI를 이용하여 뉴스 검색 서비스를 구현할 수 있다.

---

## 프로젝트 목표

지금까지 구축한 뉴스 데이터베이스를 활용하여 간단한 뉴스 검색 시스템을 완성합니다.

```text
뉴스 크롤링
    ↓
CSV
    ↓
Oracle Database
    ↓
Python 조회
    ↓
데이터 분석
    ↓
FastAPI 서비스
```

---

## 이번 장의 실습 파일

### Python

```text
src/analysis_news.py
```

## 구현 기능

### 1. 언론사별 기사 수

- GROUP BY 조회
- Plotly 막대그래프

### 2. 뉴스 목록 조회

- Oracle SELECT
- DataFrame 출력

### 3. 키워드 검색

예)

AI

반도체

로봇

### 4. FastAPI 화면

- 전체 뉴스 조회
- 키워드 검색
- 언론사 검색
