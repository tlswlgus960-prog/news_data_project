# 06. 뉴스 데이터 검색

## 학습목표

- SELECT 문을 이용하여 뉴스를 검색할 수 있다.
- WHERE, ORDER BY, LIKE, GROUP BY를 사용할 수 있다.
- Python으로 조회 결과를 DataFrame으로 가져올 수 있다.

---

## 이번 시간 학습 흐름

```text
SELECT
   ↓
WHERE
   ↓
ORDER BY
   ↓
LIKE
   ↓
GROUP BY
   ↓
Python(DataFrame)
```

## 주요 조회 예제

- 전체 뉴스 조회
- 언론사별 뉴스 조회
- AI 키워드 검색
- 최신 뉴스 조회
- 언론사별 기사 수 집계

실습은 SQL 파일을 먼저 실행한 뒤 Python에서 같은 SQL을 실행하여 DataFrame으로 확인합니다.

## 핵심 정리

- SELECT는 데이터를 조회한다.
- WHERE는 조건을 지정한다.
- ORDER BY는 정렬한다.
- GROUP BY는 집계한다.
- Python에서는 pandas.read_sql()을 사용할 수 있다.
