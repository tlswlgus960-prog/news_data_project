# 3. 데이터(Data)란?

데이터(Data)는 사실(Fact)을 표현하는 값입니다.

예를 들어 뉴스 기사에는 다음과 같은 데이터가 존재합니다.

| 뉴스번호 | 언론사 | 기사제목 | 수집일 |
|----------|--------|----------|---------|
| 1 | 연합뉴스 | AI 산업 성장 | 2026-08-01 |

이처럼 하나의 뉴스도 여러 개의 데이터로 구성됩니다.

---

# 4. 데이터베이스(Database)란?

데이터베이스(Database)는 데이터를 체계적으로 저장하고 관리하는 공간입니다.
데이터를 정리하는 공간임.

데이터베이스를 사용하면

- 대용량 데이터를 저장할 수 있다.
- 원하는 데이터를 빠르게 검색할 수 있다.
- 여러 사용자가 동시에 사용할 수 있다.
- 데이터를 안전하게 관리할 수 있다.

---

# 5. 왜 데이터베이스가 필요한가?

우리는 네이버 뉴스를 크롤링하여 CSV 파일을 생성했습니다.

```
2026-08-01.csv
2026-08-02.csv
2026-08-03.csv
...
```

CSV 파일이 계속 증가하면

- AI 기사 검색
- 특정 언론사 기사 검색
- 날짜별 기사 검색
- 언론사별 기사 개수 확인

과 같은 작업이 매우 어려워집니다.

따라서 데이터를 하나의 데이터베이스에 저장하고 SQL로 검색해야 합니다.

---

# 6. 데이터베이스의 역사

데이터 관리 방식은 다음과 같이 발전했습니다.

```
파일(File)

↓

계층형 데이터베이스

↓

네트워크형 데이터베이스

↓

관계형 데이터베이스(RDBMS)
(현재 개발자가 많이 사용)
↓

NoSQL
(현재 개발자가 많이 사용. 관계없이 파일 구조대로 싹 다 저장하자) -> 개발자 많이 사용 2개를 클라우드로 구축할거냐, 로컬로 구축할거냐 차이가 있음.
↓

Cloud Database
(구글같은 가상공간 클라우드에 저장)
```

이번 과정에서는 가장 널리 사용되는 관계형 데이터베이스(RDBMS)를 학습합니다.

---

# 7. 데이터베이스 종류

## ① 계층형 데이터베이스

- 트리(Tree) 구조
- 부모-자식 관계
- 구조 변경이 어려움

## ② 네트워크형 데이터베이스

- 여러 관계 표현 가능
- 구조가 복잡함

## ③ 관계형 데이터베이스(RDBMS)

- 최소단위인 테이블(Table) 기반
- SQL 사용 (데이터베이스에 구축되어있는 걸 꺼내오거나 들어오거나 데이터베이스의 언어임)
- 가장 많이 사용되는 데이터베이스

예)

- "Oracle" 가장 대표적
- MySQL
- PostgreSQL
- Microsoft SQL Server

## ④ NoSQL (쿼리하지 않고 바로 꺼내는 데이터베이스)

- 비정형 데이터 저장
- 대용량 데이터 처리
- MongoDB, Redis

---

# 8. 관계형 데이터베이스(RDBMS)

관계형 데이터베이스는 데이터를 테이블 형태로 저장합니다.

```
Table

┌──────────────────────┐
│ NEWS                 │
├──────────────────────┤
│ NEWS_NO              │
│ PRESS_NAME           │
│ TITLE                │
│ REG_DATE             │
└──────────────────────┘
데이터프레임을 영구적으로 계속 저장해나가는 게 데이터 베이스.

```

우리 프로젝트에서도 뉴스 데이터를 하나의 테이블로 저장합니다.

---

# 9. DBMS(Database Management System)

DBMS는 데이터베이스를 생성하고 관리하는 프로그램입니다.

대표적인 DBMS

- Oracle Database
- MySQL
- PostgreSQL
- SQL Server

DBMS를 사용하면 SQL을 통해 데이터를 쉽게 관리할 수 있습니다.

---

# 10. Oracle Database 소개

Oracle Database는 기업에서 가장 많이 사용하는 관계형 데이터베이스 중 하나입니다.

특징

- 대용량 데이터 처리
- 높은 안정성
- SQL 표준 지원
- Python 연동 가능
- 다양한 기업에서 사용

이번 과정에서는 Oracle 11g를 사용하여 뉴스 데이터베이스를 구축합니다.

---

# 11. 데이터베이스의 구성요소

```
Database
    │
    ├── Table
    │      ├── Row
    │      └── Column
```

- Database : 데이터 저장 공간
- Table : 데이터를 저장하는 표 (데이터프레임임)
- Column : 데이터의 속성(열)
- Row : 하나의 데이터(헹)

---

# 12. 테이블(Table), 행(Row), 열(Column)

| 구성요소 | 의미 | 예시 |
|----------|------|------|
| Table | 데이터 저장 공간 | TBL_NEWS |
| Column | 데이터 항목 | TITLE |
| Row | 하나의 데이터 건수 | 뉴스 1건 |

---

# 13. 기본키(Primary Key)

기본키는 데이터를 구분하는 고유한 값입니다.

예) (주민번호 같은)

```
NEWS_NO
```

특징

- 중복 불가 (unique)
- NULL 불가 (not null)
- 하나의 행을 대표 (대표할 수 있는 데이터)
-> 기본키를 찾을 수 없으면, 새롭게 만들어서 써야 한다. 숫자를 1번부터 순서대로 부여한다.

---

# 14. SQL이란?

SQL(Structured Query Language)은 데이터베이스를 사용하는 언어입니다.
내가 쿼리 명령 한 대로만 실행한다.

---

# 15. SQL 종류

| 종류 | 주요 명령 |
|------|-----------|
| DDL(테이블만들기) | CREATE, ALTER(수정), DROP |
| DML | INSERT, UPDATE, DELETE |
| DQL(조회) | SELECT |
| TCL(컨트롤) | COMMIT(저장), ROLLBACK(되돌리기) |
| DCL | GRANT, REVOKE |

이번 과정에서는 DDL → DML → SELECT 순서로 실습합니다.

# 17. 핵심정리

- 데이터는 정보를 표현하는 값이다.
- 데이터베이스는 데이터를 체계적으로 저장하고 관리하는 공간이다.
- 관계형 데이터베이스는 테이블 기반으로 데이터를 관리한다.
- Oracle은 대표적인 RDBMS이다.
- SQL을 이용하여 데이터를 저장하고 검색한다.
